🔒

Privacy-Preserving

Raw network traffic never leaves the edge node. Only model weight updates (state_dict) are shared with the aggregation server.

🧠

Class-Incremental Learning

Rehearsal buffers (200 exemplars) and teacher-student distillation preserve knowledge of old attack classes when new threats emerge.

⚖️

Adaptive Weighting

Unlike FedAvg's uniform averaging, weights are dynamically computed: α·data_size + β·val_score + γ·staleness penalty.

📡

Communication Efficient

Optional float16 quantization reduces model update transmission by ~50%. Communication bytes logged per round.
