ABSTRACT
The increasing adoption of Internet of Things (IoT) devices has significantly expanded the attack surface for cyber threats. Traditional Intrusion Detection Systems (IDS) rely on centralized training and frequent retraining, leading to privacy concerns and poor adaptability to emerging attacks.
This project is based on the IEEE TNSM 2026 paper "A Federated and Incremental Network Intrusion Detection System for IoT Emerging Threats." The base system integrates Federated Learning and Class Incremental Learning to enable privacy-preserving collaborative training while continuously learning new attack classes. The proposed work further enhances the system by introducing an Adaptive Federated Aggregation strategy to improve model aggregation under heterogeneous client environments, aiming to achieve better intrusion detection performance, scalability, and robustness in distributed IoT networks.

PROBLEM STATEMENT
   Existing IoT Intrusion Detection Systems suffer from centralized data dependency, privacy issues, and limited adaptability to newly emerging cyber-attacks. Although the base paper addresses these issues using Federated Class Incremental Learning, the aggregation process still relies on predefined federated aggregation algorithms that may not perform optimally under heterogeneous client data distributions. Therefore, there is a need for a more adaptive aggregation mechanism to improve global model performance while maintaining privacy and continuous learning. 

OBJECTIVES
Study the Federated Class Incremental Learning framework proposed in the base paper.
Design an Adaptive Federated Aggregation strategy for heterogeneous IoT environments.
Improve intrusion detection performance under non-IID client data.
Preserve user privacy by avoiding raw data sharing.
Compare the proposed model with the base paper using standard evaluation metrics.

EXISTING SYSTEM
Multiple IoT clients locally train an Intrusion Detection System using Class Incremental Learning.
Local model parameters are shared with a Federated Server.
The server aggregates local models using FedAvg, FedProx, or FedDyn.
The updated global model is redistributed to all clients.
The system continuously learns new attack classes while preserving previously learned knowledge.



DRAWBACKS OF EXISTING SYSTEM
Uses predefined aggregation algorithms (FedAvg, FedProx, FedDyn).
Performance depends on the selected aggregation method.
Client heterogeneity may reduce global model performance.
Frequent synchronization increases communication overhead.
Scope exists for improving aggregation efficiency and scalability.

CURRENT IMPLEMENTATION STATUS AND PRELIMINARY RESULTS

Implemented:
- Centralized federated-learning simulation with multiple IoT clients and a server.
- Client-side local training with rehearsal memory, knowledge distillation, and prototype extraction.
- Adaptive aggregation using client data size, validation performance, and update recency.
- FedAvg, data-weighted aggregation, and FedProx comparison modes.
- Reproducible random seeds, held-out validation data, non-IID-ready client partitions, and optional class-incremental stages.
- Per-round accuracy, macro Precision, Recall, F1-score, prototype accuracy, aggregation weights, and communication-size estimates.
- TON-IoT preprocessing, synthetic experiments, comparison plots, and a repeatable CIL demonstration.

Preliminary same-seed synthetic comparison (5 clients, 3 rounds, 1 local epoch):

Strategy             Accuracy       Macro-F1       Communication/round
Adaptive             0.3770         0.1959         113,980 bytes
FedAvg               0.3490         0.2486         113,980 bytes
Weighted             0.3490         0.2486         113,980 bytes
FedProx              0.3470         0.2494         113,980 bytes

Interpretation:
Adaptive produced the highest accuracy in this preliminary run, but its macro-F1 was lower. Accuracy alone is therefore insufficient, especially for imbalanced intrusion-detection classes. More seeds, longer training, and per-class evaluation are required before claiming overall improvement.

Two-seed validation (2 rounds, 1 local epoch):
Adaptive: mean accuracy 0.3665 +/- 0.0085; mean macro-F1 0.2106 +/- 0.0288
FedAvg: mean accuracy 0.3705 +/- 0.0045; mean macro-F1 0.2026 +/- 0.0207
Weighted: mean accuracy 0.3705 +/- 0.0045; mean macro-F1 0.2026 +/- 0.0207
FedProx: mean accuracy 0.3740 +/- 0.0010; mean macro-F1 0.2007 +/- 0.0189

The validation run shows Adaptive has the best mean macro-F1, while FedProx has the best mean accuracy. These results are preliminary and require more seeds and longer training.

Not yet implemented:
